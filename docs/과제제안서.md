## 1. 개요

- LLM 에이전트(Claude 등)에게 업무를 지시할 때, **맥락(context)을 충분히 제공할수록 결과 품질이 높다.** 그러나 그 맥락은 여기저기 흩어져 있고 일부는 **휘발**된다.
- **context-DB**는 흩어지고 사라지는 맥락 데이터를 **관계형 DB에 구조화 저장**하고, 에이전트가 **skills를 통해 스키마를 숙지한 뒤 필요한 맥락만 SQL로 질의**해 가져가도록 하는 프로그램이다.

## 2. 배경 및 문제 정의

- **문제 1 — 휘발성 데이터**: 하이웍스 메신저 등 협업 대화는 시간이 지나면 검색·복구가 어렵고, 결정 근거가 사라진다.
- **문제 2 — 분산된 외부 소스**: 공유 문서 링크·논문·서버 정보 등이 여러 곳에 흩어져 재사용이 힘들다.
- **문제 3 — 맥락 주입의 비효율**: 매번 사람이 관련 맥락을 찾아 붙여 넣어야 하며, 누락·중복이 발생한다.
- → 맥락을 **한곳에 구조화 저장**하고 **질의로 꺼내 쓰는** 저장소가 필요하다. (제안자는 Physical AI 개발 과정에서 이 문제를 직접 경험함.)

## 3. 목표 및 기대효과

- **목표**: 휘발성 대화·외부 소스를 정규화된 관계형 스키마에 적재하고, 프로젝트·기간·태그·키워드로 **정확히 질의**해 에이전트에 제공한다.
- **기대효과**: (1) 맥락 유실 방지 (2) 맥락 주입 자동화·표준화 (3) 결정 이력 추적성 확보.

## 4. 주요 기능 (요구사항)

| # | 기능 | 설명 | 우선순위 |
|---|---|---|---|
| F1 | 맥락 적재 | 하이웍스 로그(.txt)·메모·문서 발췌를 `context_item`으로 저장 | 필수 |
| F2 | 외부 소스 저장 | 링크·문서·논문·서버정보를 `source`/`link`로 저장 | 필수 |
| F3 | 분류·태깅 | 프로젝트·소스유형·태그(M:N)로 분류 | 필수 |
| F4 | 키워드/전문 검색 | FTS로 내용 검색 | 필수 |
| F5 | 조건 질의 | 프로젝트·기간·작성자·태그 기준 조회(대표 뷰/쿼리) | 필수 |
| F6 | skills 연동 | 에이전트가 스키마 숙지 후 질의 템플릿으로 맥락 조회 | 필수 |
| F7 | 질의 로그 | 에이전트 질의 이력 기록 | 선택(2차) |

## 5. 데이터베이스 활용 방안 (과제 핵심)

- **정규화된 관계 설계(3NF)**: 조회 테이블(`source_type`), 1:N 관계(프로젝트→소스→맥락항목), **M:N 관계(맥락항목↔태그, 접합 테이블)** 로 중복 제거.
- **키·제약**: PK/FK, UNIQUE, NOT NULL, CHECK로 무결성 보장.
- **인덱스·전문검색**: 조회 컬럼 인덱스 + **FTS5 가상 테이블**로 내용 검색.
- **뷰·집계 쿼리**: 타임라인 복원·프로젝트별 최근 맥락·태그별 링크 목록 등 대표 질의를 뷰로 제공.
- → "저장(정규화) → 색인 → 질의(SQL/FTS)"의 DB 전 과정을 실습·평가할 수 있다.

## 6. 기술 스택

- **DB**: SQLite 3(파일 기반, 무설치) + **FTS5**(내장 전문검색). *(대규모 확장 시 PostgreSQL + tsvector로 이관 가능하도록 표준 SQL 유지.)*
- **적재**: Python 3(표준 라이브러리 `sqlite3` + 로그 파서).
- **연동**: 에이전트 skill 문서(스키마 설명 + 파라미터화 SQL 템플릿).

## 7. 범위 (Scope)

- **포함(MVP)**: 스키마·DDL, 하이웍스 로그/링크 적재 스크립트, 대표 질의·뷰·FTS, skill 연동, 시연.
- **제외(차기)**: 의미(벡터) 검색·임베딩, 웹 UI, 실시간 수집, 권한/멀티유저, 자동 크롤링. → 단기 개발을 위해 **의도적으로 제외**.

## 9. 평가 관점 (기대 성과)

- 정규화(3NF)·관계(1:N, M:N)·제약·인덱스·전문검색이 **동작하는 DB로 구현**됨.
- 실제 휘발성 데이터(하이웍스 로그)를 적재하고, **질의로 맥락을 정확히 회수**하는 시연.
- 에이전트가 skill을 통해 **스스로 질의**해 맥락을 가져오는 end-to-end 흐름.
